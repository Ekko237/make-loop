# make-loop

一个给 Claude Code / Codex 用的技能：把一句大白话的任务，改写成能放心让 AI 自己一轮一轮跑下去的循环（loop）任务说明。

一个循环就三段：**目标**（要做什么）→ **过程**（怎么做）→ **检查迭代**（做完检查，再接着改）。里面写全五件事：目标是什么、每轮做什么、怎么检查、记录什么、什么时候停。

它会自动补上最常见的坑：

- 目标要能检查，不能写「更好看」这种空话。
- 每一项「过」都要有证据，「试一遍」要真的操作。
- 主观质量用靠谱的独立评审：统一的尺子、定标卷、多人取平均、和最好版本并排比。
- 定期让人本人看前后对比，防止 AI 评审集体看走眼。
- 刹车写全：做完了、卡住了、没进展、来回摆、上限、暂停。并按「有人 / 无人值守」决定是停下来问，还是绕过去接着跑。
- 花钱和不可逆的事写进红线。

范例见 `references/examples.md`。

## 安装

```bash
bash install.sh          # 自动装到 ~/.claude/skills 和/或 ~/.codex/skills
bash install.sh claude   # 只装 Claude Code
bash install.sh codex    # 只装 Codex
```

装好后，说「帮我变成 loop」「让它自己一轮一轮改到好」，或者 `/make-loop 你的任务`。
